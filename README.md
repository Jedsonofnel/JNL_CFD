# JNL CFD

A guile-embedded CFD project for version-controllable CFD simulations and 
straightforward parameterisation of studies.

## Initial Usage

Once built, use `bin/cli` to open up the REPL - this is the main interface
for the program.

## Building

Dependencies are
- Raylib
- Guile scheme

On Arch Linux these can be installed via `sudo pacman -S guile raylib`.
